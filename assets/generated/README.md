# Generated Art Pack

This directory is reserved for the finished original image pack used by the CAW Helper visual system.

The application is intentionally resilient: generated JPG layers are preferred when present, while the repository's original SVG study assets act as a deterministic fallback so the GitHub build never renders a broken-image state.

The finished generated pack is kept as a portable artifact alongside the repository because the connected GitHub file API used for this build does not expose a local-binary upload operation.

## Required rule

Never replace original artwork with scraped, traced, or copied wrestling imagery. New visual assets should be created specifically for CAW Helper and catalogued by name, purpose, and world.
