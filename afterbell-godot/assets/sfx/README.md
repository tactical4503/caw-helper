# Drop-in sound effects

Put a file here named after the cue (`.ogg`, `.wav` or `.mp3`) and the game plays it instead of
its synthesized placeholder. Missing files keep the placeholder. Short one-shots: ideally under 2 s,
trimmed tight to the start.

| File name | When it plays |
|---|---|
| `bell` | chair strikes the service bell (the big one) |
| `chime` | two-note tell before a sale sign is thrown |
| `reflect` | a sign is returned with the flat of Knock |
| `heavy` | wound heavy strike released |
| `click` | each of the three spring clicks while winding |
| `swing` | light attack, throws, dodge |
| `knock` | dull wooden hit on the locked chair / sign into the catcher |
| `thud` | blocked sign, padded stop, impacts |
| `hurt` | Ren takes a hit |
| `squeak` | chair casters |
| `rattle` | clothes-rack wheels before a shove |
| `spring` | gate release / reward |
| `pip` | Pip's two-note reply, biscuit eaten |
| `amb_cosmetics` | looping room tone in Cosmetics (store hum, distant chatter) |
| `amb_court` | looping room tone in the Menswear court |
